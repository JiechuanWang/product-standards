# 牙膏

- **分类**：生活用品 / 个护洗护
- **判定维度**：C · 底线 + 体验混合
- **更新日期**：2026-08-23

## 标准（底线）

- 国内底线：**GB 8372《牙膏》**（强制性国标）

## 体验维度（本条目核心）

- 本次要解决的具体问题：**刷完牙口腔黏膜脱屑（起薄皮）**，主要由发泡剂 **SLS（十二烷基硫酸钠）** 引起 → 换「无 SLS」牙膏

## 已验证品牌（无 SLS）

| 品牌 | 说明 | 购买地 |
|---|---|---|
| Sensodyne（英国 Haleon） | 绝大多数无 SLS；推荐「每日保护」或「深层清洁」款，避开含氟化亚锡的「瞬间舒缓」款（易染色） | 莫斯科药店/大超市 |
| R.O.C.S.（Р.О.К.С.） | 俄本土，包装标「без SLS」，Bionica 系列主打温和 | 药店/超市 |
| Splat（СПЛАТ） | 部分系列无 SLS，看标签 | 超市 |
| Biorepair（意大利） | 无 SLS，偏贵 | ВкусВилл/药店 |

## 国外对照

- Sensodyne 本身即国外品牌（Haleon），无 SLS 配方为行业标准做法

## 结论

- 要不起皮 → 认准「без SLS / без лаурилсульфата натрия / SLS-free」，闭眼选 Sensodyne 或 R.O.C.S. 标「без SLS」的款
