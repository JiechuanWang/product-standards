## 为什么做

很多人刷到「XX 不达标」「XX 标准比国外低」，但不想、也不会每个都去查。这里把结论**提前查好、交叉验证好、定期更新**，你进来直接搜。

## 判断一个产品的依据（判定维度三分法）

不要给没有标准的东西硬套标准，先分清楚这个品类靠什么判断「好不好」：

| 维度 | 含义 | 例子 | 查什么 |
|---|---|---|---|
| **A · 标准驱动** | 有硬性安全/卫生标准，达标是底线 | 卫生巾、食品接触用品、家电安全 | 最严标准 + 达标证据 |
| **B · 参数/功效驱动** | 无统一达标线，比的是性能 | 清洁剂去污力、空气净化器 CADR | 关键参数 + 实测口碑 |
| **C · 底线+体验混合** | 有安全底线，但「更好」靠功效/舒适 | 牙膏、家电 | 底线达标 + 体验/参数 |

## 证据强度分级（怎么才算「真达标」）

同一句「符合标准」，可信度天差地别：

| 等级 | 证据形式 |
|---|---|
| ⭐⭐⭐⭐⭐ | 第三方检测**报告原文**写「符合 GB XXXX」，且所检项目覆盖核心指标 |
| ⭐⭐⭐⭐ | 第三方**认证证书**（技术依据指向国标，如中卫安「可接触食品」认证） |
| ⭐⭐⭐ | 包装印「执行标准 GB/T XXXX」= 仅推荐性性能标准，无安全标准 |
| ⭐⭐ | 只有「食品级/环保/无毒」等宣传语，无标准号、无报告 |
| ⭐ | 无任何背书 |

判定四要点：① 检验报告 ≠ 认证证书；② 看检测机构 CMA/CNAS 资质；③ 看「所检项目」是否覆盖核心指标；④ 看标准版本年份（优先新版）。

## 权限与协作

- 本仓库由维护者（王孑川）管理，他人**不能直接修改**维护者的条目
- 他人可：**Issues** 评论留言；**Pull Request** 提交新增/修改（维护者审核后合并进 `community/` 区）
- 维护者的已验证结论在各分类目录下；社区贡献统一放 `community/`

## 更新机制（半自动）

- 定期用 **smart-buy skill** 重验「已达标品牌是否仍达标、有无更优」，写回仓库并附更新日期
- 触发可自动化（GitHub Actions 定时），但「判断是否达标」需联网搜索+判断，无法全自动

3. 维护者定期审核、交叉验证后合并
